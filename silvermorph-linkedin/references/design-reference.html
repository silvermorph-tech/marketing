FRAME, NEVER BROKEN

No header logo, tag or footer strip: LinkedIn already shows the company name above the post. 64 px margins. One idea per poster. Headline readable at 360 px wide. English only.

IMAGES

No AI-generated images. Photos, logos and screenshots come from the team and are placed into the HTML as supplied. Atmosphere is CSS and SVG only.

HOW TO MAKE ONE

Pick a layout below, run render_poster.py --layout ID --set key=value --out poster.png. No layout fits? Write HTML and use --html.
